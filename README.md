# 👑 SOVEREIGN : GLOBAL CONQUEST
### لعبة السيطرة العالمية الجماعية (مستوحاة من RISK)

---

## 📖 فكرة اللعبة
لعبة ويب جماعية استراتيجية تجمع بين هيبة لعبة **RISK** الكلاسيكية ونظام التحكيم المباشر للفعاليات والتجمعات:
- **شاشة المضيف الرئيسية (Host Command Center):** تُعرض على شاشة كبيرة أو كمبيوتر، وتحتوي على خريطة العالم التكتيكية الكاملة بـ 42 إقليماً و 6 قارات، مع إدارة التعزيزات، التحصين، الغزو، والأدوار.
- **جوالات اللاعبين (Mobile Controllers):** يدخل اللاعبون عبر مسح رمز **QR** أو إدخال كود الغرفة مباشرة دون الحاجة لإنشاء حساب، ليختاروا مجموعاتهم ويستقبلوا تنبيهات الهجوم اللحظية.
- **نظام التحكيم الشفهي الفوري (بدون نرد):** المضيف يطرح الأسئلة شفهياً، ويضغط فوراً على **«هجوم صحيح»** أو **«دفاع صحيح»** ليحسم المعارك ويخصم القوات ويسقط الأراضي في أجزاء من الثانية.

## 🚀 التشغيل المحلي (Local Development)

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تشغيل السيرفر في وضع التطوير:
```bash
npm run dev
```
سيعمل التطبيق على الرابط: `http://localhost:3000`

### 3. ربط الجوالات على نفس شبكة الواي فاي (Wi-Fi):
لجعل الهواتف تنضم لشاشتك محلياً:
1. احصل على عنوان IP المحلي لجهازك (مثال: `192.168.1.50`).
2. افتح من الجوال: `http://192.168.1.50:3000` أو امسح رمز الـ QR الذي يظهر في شاشة المضيف.

## 🌐 خيارات النشر السحابي (Deployment)

1. **Google Cloud Run:** متوافق تماماً وجاهز مع `node server.ts` ومتغير `PORT`.
2. **Render / Railway / Fly.io:** اختر Web Service وشغّل `npm run build` ثم `npm start`.
3. **GitHub Pages (الاستضافة الثابتة):**
   التطبيق مزود بمحرك محلي تلقائي (In-browser fallback) للعمل حتى في حال رفعه على استضافة ثابتة، ولدعم اللعب بين جوالات متعددة عبر الإنترنت يُفضل ربطه برابط السيرفر عبر متغير البيئة:
   `VITE_SERVER_URL="https://your-backend-service.com"`

## 📋 هيكلية المشروع (Project Architecture)

```
├── server.ts                  # خادم Express + Socket.IO لإدارة الحالة اللحظية
├── src/
│   ├── components/
│   │   ├── Host/              # لوحة تحكم المضيف وإدارة المراحل
│   │   ├── Map/               # خريطة العالم التفاعلية (SVG World Map)
│   │   ├── Battle/            # ساحة التحكيم الفوري (هجوم صحيح / دفاع صحيح)
│   │   ├── Mobile/            # واجهة اللاعبين للجوال والتنبيهات
│   │   ├── Lobby/             # غرف الانتظار وإنشاء الأكواد و QR Code
│   │   └── Modals/            # شاشة النصر الإمبراطوري والإحصائيات
│   ├── data/
│   │   └── riskMapData.ts     # بيانات الأقاليم الـ 42 والقارات الست
│   ├── services/
│   │   └── socket.ts          # ربط Socket.IO والمزامنة الشبكية والمحلية
│   ├── utils/
│   │   └── audio.ts           # المؤثرات الصوتية بمحرك Web Audio API
│   └── types/
│       └── game.ts            # أنواع البيانات
├── Dockerfile                 # إعداد الحاوية للتشغيل في أي بيئة
└── .github/workflows/         # فحص البناء الآلي في GitHub Actions
```
